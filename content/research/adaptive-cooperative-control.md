This project investigates resilient cooperative control with constraints on communication, safety envelopes, and dynamic task reassignment.

## Key Questions

- How can adaptation remain stable under intermittent sensing?
- Which coordination architectures scale best with heterogeneous platforms?
- How can safety constraints be enforced in real time?
